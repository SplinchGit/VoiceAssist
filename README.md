# VoiceAssist

Junction is a personal social + notification control tower. This repository starts with
foundation planning to support a cross-platform Android + PC build while keeping the
initial milestone small and achievable.

## Goals
- Unify notifications into a single, calm inbox.
- Provide deliberate response workflows (no spammy alerts).
- Support routines and healthy attention management.

## Foundation plan (phase 0)
- Establish a shared core domain model that works across Android and PC.
- Build platform shells that can render the same feed UI and connect to the shared core.
- Keep the first milestone focused on a mock/local notification feed.

See `docs/foundation.md` for the cross-platform architecture outline and first
implementation milestones.
